# 指標定義

所有指標都在 `scripts/yewan_cohort.py` 中實作，這份文件是給人看的說明版本。若兩者不一致，以程式為準，並請修正本文件。

## 共用設定
| 名稱 | 定義 |
|---|---|
| 資料期間 | 兩張捐款表中最早到最晚的捐款日（2025-11-01 ~ 2026-10-31） |
| 觀察截止日 `as_of` | 預設等於資料期間最後一天 |
| 期間捐款人 | 期間內至少有一筆定期扣款或單筆捐款的聯絡人 |
| 首捐日期 | 期間內最早的一筆交易日期（**不使用** 聯絡人.建立日期） |
| 年輕支持者 | 年齡級距為「20歲以下」或「20-24歲」 |
| 期間新捐款人 | 期間內首捐為**單筆**，且期間開始前**沒有任何**定期方案（排除早已存在的定期捐款人） |
| 暖機期 | 資料期間的前 30 天。這段期間的「首捐」很多其實是舊捐款人，所以不放進活動基準期 |

## 任務二：定期定額留存
| 指標 | 定義 | 為什麼這樣算 |
|---|---|---|
| 停止 | `狀態` ∈ {暫停中, 已失敗}；進行中、待處理視為「仍在觀察中」（設限 censored）；已完成另外計算 | 待處理多半是暫時狀態，不宜直接算流失 |
| 第 k 期停止率（hazard） | 於第 k 期停止的方案數 ÷ 執行期數 ≥ k 的方案數 | Kaplan–Meier 做法。單看「停止者的期數分布」會被各期人數影響 |
| 累積存活率 | ∏(1 − hazard) | 可以讀成「撐過第 k 期的機率」 |
| 停止與期數是否相關 | 執行期數 × 停止 的卡方獨立性檢定 | 若兩者無關，後段 hazard 上升只是分母變小的機械效果 |
| 真正扣滿約定期數 | 約定總期數 > 0 且 執行期數 ≥ 約定總期數 | `已完成` 狀態並不保證真的扣滿 |
| 有扣款失敗 | 請款次數 > 成功次數 | |
| 失敗後已恢復 | 有扣款失敗，且最近一次成功扣款日 > 最近失敗日期 | 用來衡量「挽回」的效果 |
| 沉默天數 | as_of − 最近一次成功扣款日 | 7／30 天預警分級的依據 |
| 靜默流失 | 狀態＝進行中，但沉默天數 > 45 天 | 系統顯示仍在進行，實際上已經沒在扣款 |
| 月流失 | 最後一次扣款落在 m 月，之後到 as_of 都沒有再扣款。距 as_of 不足「扣款間隔 P90」天的月份不判定 | 避免把「只是還沒扣到」誤認為流失 |
| 定期 Cohort 留存 | 以期間內首次扣款月份分群；M_k = 第 k 個月仍有扣款的人數 ÷ Cohort 人數 | 以「當月是否有扣款」計算，不以扣款筆數計算 |
| 之後有再開方案／加碼 | 同一人有另一個加入日期較晚的方案（約定金額較高 = 加碼） | ⚠ 野灣換卡必須重新設定方案，所以「再開方案」包含換卡。要區分的話，需要 NGO 提供變更表單紀錄，或以「舊方案停止日 ≈ 新方案加入日、金額相同」來判斷為換卡 |

### 優先提醒名單的計分規則（可以調整，但必須保持透明）
| 條件 | 分數 | 建議行動 |
|---|---|---|
| 扣款失敗且尚未恢復（非已完成） | +40 | 付款失敗挽回：提醒更新付款資訊 |
| 暫停中 | +25 | 恢復邀請 |
| 待處理 | +20 | 確認付款設定 |
| 靜默流失 | +25 | 靜默關懷 |
| 剩 0–2 期就到期（仍在進行） | +15 | 續約邀請 |
| 已完成且尚未續約 | +20 | 續約／加碼邀請 |
| 已失敗 | +5 | 低優先挽回 |
| 約定金額 ÷ 100（上限 15） | +0~15 | — |
| 已扣款 6 期以上 | +5 | — |

「建議行動」取符合條件中排在最上面的那一項；「理由」欄位列出所有符合的條件。

## 任務三：支持時刻
| 指標 | 定義 |
|---|---|
| 活動前日均新捐款人 | 活動日前 14 天（不含暖機期）每天期間新捐款人的平均數 |
| 活動後新捐款人 | 活動當天起 7 天內的期間新捐款人數 |
| 增幅倍數／p 值 | 觀察值 ÷（日均 × 7）；p = P(X ≥ 觀察值 \| Poisson(預期))，單尾 |
| 對應管道占比 | 活動窗內新捐款人中，首捐管道與活動類型相符的比例（電子報→電子報、市集→市集、社群貼文→社群、媒體報導→搜尋/官網），並與基準期比較 |
| N 天內再捐率 | 首捐後 N 天內（不含首捐當筆）有任何捐款。只計算觀察期滿 N 天的人 |
| 轉為定期扣款率 | 首捐後出現定期扣款。⚠ 本資料期間內幾乎沒有新加入的定期方案，所以這個比率只能當作代理指標 |

## 判定規則
- 顯著水準 α = 0.05。
- 分群比較使用卡方獨立性檢定，並用 **Bonferroni 校正**（p × 維度數）。
- 最小組樣本 < 30 時，判定為「樣本太少：不宜下結論」。
- 比率都附上 Wilson 95% 信賴區間。
