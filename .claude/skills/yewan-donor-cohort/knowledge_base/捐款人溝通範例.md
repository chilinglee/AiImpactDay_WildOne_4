# 捐款人溝通範例

- 來源：官網捐款頁、《2025 野灣年度報告》
- 整理日期：2026-11-14

## 語氣
- 以**單一動物的故事**為主軸，並具體說明金額的用途（「800 元＝失親動物的一罐奶粉」）。
- 誠實面對失敗與死亡（年報中有安樂死、救援前死亡的數字），不渲染悲情。
- 常用語：「重返山林」、「與野共榮」、「每一筆捐款都是一份沉甸甸的託付」。
- 秘書長在年報中的結語引用獸醫師的話：「如果牠們沒有了，那我們住在這裡，真的太寂寞了。」

## 可以引用的故事素材（2025 年報）
| 故事 | 適合的信件類型 |

| 臺灣獼猴「咕嚕」：曾被私養，治療一個月後毛髮恢復 | 恢復邀請（展示改變） |
| 柴棺龜 251001R01：花蓮光復水災，殼裂住院四個月，2026/1/30 野放 | 扣款失敗挽回（「您的支持讓牠回家了」） |
| 黑眉錦蛇與 14 顆蛋：照顧 80 天後野放 14 條小蛇 | 續約邀請（長期陪伴的成果） |
| 24 小時內收治 3 隻黑熊 | 緊急募款、加碼邀請 |
| 2025 年野放 418 隻、受理 1,296 件 | 年度感謝信 |

## 信件草稿原則（給 AI）
1. 一封信只講一隻動物、只有一個行動（更新付款、恢復、續約）。
2. 金額用途沿用官網的文案。
3. 不可以編造動物故事或數字，只能引用本文件或年報中的內容。
