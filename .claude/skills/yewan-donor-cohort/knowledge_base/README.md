# 野灣 Knowledge Base

這個資料夾放野灣野生動物保育協會的背景資料，讓 AI 在解讀數字、撰寫信件時能貼近組織的真實情境。

## 撰寫原則
- 一個主題一個檔案，檔名用中文，例如 `組織概況.md`、`募款與溝通管道.md`。
- 每份文件開頭標註**來源連結**和**整理日期**。
- 只寫事實與引用；推論請另外標註「推論」。
- 模擬資料中的活動時間軸是虛構的，**不要**寫進這裡。

## 已收錄（2026-11-14 依官網與 2025 年報整理）
| 檔案 | 內容 | 用在哪個分析步驟 |
|---|---|---|
| 組織概況.md | 使命、成立背景、救援工作範圍、規模 | 簡報脈絡、信件語氣 |
| 募款與溝通管道.md | 定期定額方案、捐款頁、電子報、社群、市集 | 解讀捐款管道、設計提醒信 |
| 捐款人溝通範例.md | 過去的感謝信、成果報告用語 | 產生信件草稿 |
| 年度節奏.md | 救援旺季、年度報告、年底募款 | 判讀季節性、安排提醒時機 |
| 名詞對照.md | 平台欄位、狀態代碼的實際意義（向 NGO 確認後填寫） | 修正 metrics.md 的定義 |
