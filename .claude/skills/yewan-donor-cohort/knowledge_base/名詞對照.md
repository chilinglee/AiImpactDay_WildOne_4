# 名詞對照（模擬資料 ↔ 野灣實際系統）

- 來源：Field_Guide.csv、官網捐款頁、FAQ
- 整理日期：2026-11-14

| 模擬資料 | 實際系統（官網） | 分析時要注意 |
|---|---|---|
| 系統編號 SYS… | CiviCRM 聯絡人 ID | |
| 性別：女性／男性／非二元/其他／未提供 | 捐款表單：生理女／生理男／其他（必填） | 真實資料不會有「未提供」，但類別名稱不同 |
| 年齡級距 | 出生日期（**選填**） | 真實資料的年齡缺漏率可能很高，「25 歲以下比例」會有偏誤 |
| 鄉鎮市區 | 聯絡地址：縣市 + 鄉鎮市區（必填） | |
| 約定總期數 = 0 | 沒有填寫期數 → 持續扣款直到通知停止 | |
| 付款工具 | 信用卡、ATM／超商、LINE Pay／Apple Pay；另有街口等平台 | 定期定額在官網上主要是信用卡 |
| 狀態：進行中／暫停中／已完成／待處理／已失敗 | CiviCRM 定期捐款狀態 | 「暫停中」「待處理」的實際意義**需要向 NGO 確認** |
| 同一人的多個定期方案 | **換卡需要重新設定新方案** | 不可以直接解讀成加碼或回流 |
| 捐款管道（單筆） | 官網沒有來源欄位 | 真實資料需要加上 UTM／活動連結才能歸因 |
| 活動時間軸 | 虛構 | 真實活動請參考年報 |
